# `img-gen`

A rust library that conveniently exposes the public API from
[`img-gen-spec`][spec-crate] and [`img-gen-renderer`][render-crate] libraries.

This library is also distributed as a Python package of the same name.

[spec-crate]: https://crates.io/crates/img-gen-spec
[render-crate]: https://crates.io/crates/img-gen-renderer
